# NeverLand

A personal repository for coding practice and algorithm solutions, primarily focused on LeetCode problems.

## About This Repository

NeverLand is a collection of programming solutions and projects, organized by algorithm patterns and data structures. This repository serves as a learning resource and reference for various coding problems.

## Contents

- **leetcode/** - LeetCode problem solutions organized by categories:
  - `Two_Pointers/` - Two pointer algorithm problems
  - `SlidingWindow/` - Sliding window technique problems
  - `PrefixSum/` - Prefix sum array problems
  - `Linked_Lists/` - Linked list data structure problems
  - `Bin/` - Binary search and binary-related problems

- **python/** - Python projects and utilities:
  - `PythonProjects/` - Various Python projects including Tic-Tac-Toe console game
  - `PythonBin/` - Python utility scripts

## Building and Running

### C++ Solutions

The repository uses a Makefile for building C++ solutions:

```bash
# Build the main executable
make

# Run the compiled program
make run

# Clean build artifacts
make clean
```

Individual LeetCode solutions can also be compiled independently:

```bash
cd leetcode/Two_Pointers/Two_Sums
g++ -std=c++17 -o solution Two_Sums.cpp
./solution
```

### Requirements

- C++ compiler with C++17 support (g++ recommended)
- Python 3.x for Python projects
